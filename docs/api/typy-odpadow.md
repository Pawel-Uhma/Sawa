# Typy odpadów

- Kategoria: Środowisko
- Właściciel: Biuro Marketingu Miasta
- Odświeżanie: codziennie
- Licencja: Creative Commons Attribution
- Endpoint: `POST https://dane.um.warszawa.pl/api/action/get_bmm_typy_odpadow`
- Opis: Zasady segregacji typów odpadów w Warszawie. Dane pochodzą z serwisu https://segregujna5.um.warszawa.pl/.

## Przykład wywołania

**Przykład wywołania dla zapytania o segregacje typów odpadów**

```
curl --location --request POST 'https://dane.um.warszawa.pl/api/action/get_bmm_typy_odpadow' --header 'Authorization: token_uzytkownika'
```
